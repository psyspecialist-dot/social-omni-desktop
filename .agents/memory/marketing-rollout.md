---
name: Marketing suite approval gates
description: User's required sequential implementation and approval rule for the marketing suite rollout.
---

Implement requested marketing features one at a time. Finish the current feature's code and local verification, report the results and any unverified live-provider behavior, and obtain the user's approval before starting the next feature.

**Why:** The user explicitly requires sequential delivery and approval after the current feature passes inspection; the broader roadmap is not permission to start its later features.

**How to apply:** Keep later email, SMS and Facebook roadmap work untouched until approval. Never describe fixture tests as verification against a real signed-in provider account.
