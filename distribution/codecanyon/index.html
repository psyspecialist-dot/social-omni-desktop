1. Install / التثبيت

Windows x64: extract the package, open Installers/Windows and run the EXE. macOS: choose the Intel x64 or Apple Silicon arm64 DMG and drag the app to Applications. Node.js is not needed for installed apps.

في Windows شغّل ملف EXE. في macOS افتح DMG المناسب لجهازك واسحب التطبيق إلى Applications. لا تحتاج تثبيت Node.js.

Publisher signing/notarization is not configured by default. Verify the seller and download before trusting unsigned software; do not disable system security globally.

2. Activate offline / التفعيل المحلي

  1. Open Settings → License.
  2. Copy Machine ID and send it privately to the seller with purchase evidence.
  3. Paste the full SN1 signed license provided by the seller and select Activate.
  4. Keep the license for reactivation on the same device.

افتح الإعدادات ثم الترخيص. انسخ معرّف الجهاز وأرسله للبائع مع إثبات الشراء. الصق الرخصة الموقّعة كاملة واضغط تفعيل. احتفظ بها لإعادة تفعيل الجهاز نفسه.

No activation server is needed. Device-bound signatures are verified locally and stored using OS encryption. A different device needs a different license. Social-network actions still need internet.

A signed application license is not an Envato purchase code. Purchase validation is performed by the seller. Offline certificates cannot be remotely revoked.

3. Copy and paste / النسخ واللصق

Ctrl+C/V on Windows, Cmd+C/V on macOS, the native Edit menu, and field context menus are supported. Machine ID is read-only and selectable. Copy verifies clipboard read-back. If copying fails, select the ID and copy manually.

تعمل اختصارات Ctrl أو Cmd وقائمة التحرير وقائمة الزر الأيمن. معرّف الجهاز قابل للتحديد والنسخ. يؤكّد زر النسخ نجاح الحافظة قبل عرض رسالة النجاح.

4. Source and configuration / المصدر والإعدادات

Extract Source/social-najhin-desktop.zip outside any pnpm workspace. See README.md for development/build commands. Change licensing-config.json and rebuild:

{ "enabled": true, "mode": "offline", "publicKey": "SELLER_PUBLIC_KEY" }

enabled:false intentionally disables checking and is clearly labelled in Settings. The private signing key and seller key-generator are not in this buyer package. Do not embed a shared secret salt. Source owners can modify and rebuild the application.

ملف الإعدادات يتيح تعطيل الفحص عند إعادة البناء. المفتاح الخاص وأداة البائع غير موجودين في حزمة المشتري. لا تضع مفتاح توقيع سرياً داخل التطبيق.

5. Support and notices / الدعم والإشعارات

A perpetual license covers the purchased release. Optional monthly/yearly plans cover updates/support, not continued use. A newer release may require renewed update entitlement. Contact your seller through the marketplace item support channel.

For detailed constraints read LICENSING.md and third-party notices. Browser sign-in, account restrictions, third-party provider credentials and consent are still required. Marketplace acceptance is subject to Envato review.

الرخصة دائمة للإصدار المشمول. التحديثات والدعم اختياريان شهرياً أو سنوياً. تواصل مع البائع عبر دعم صفحة المنتج. قبول المنتج في السوق يخضع لمراجعة Envato.
